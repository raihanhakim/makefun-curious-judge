A tiny Python program that writes one short text to intrigue the AI judge: a notebook whose last page is dated tomorrow, describing a question the reader was about to ask. The text is 229 characters, fixed and deterministic, with no network, no clock and no randomness.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
